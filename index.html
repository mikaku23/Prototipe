01PROFILE

From software engineering to informatics.

Saya mahasiswa Teknik Informatika di Universitas Malikussaleh, dengan fondasi Rekayasa Perangkat Lunak (RPL) dari SMKN 1 Karang Baru. Latar belakang SMK membentuk pengalaman awal dalam pengembangan web, perancangan sistem, basis data, pengujian, dan pemecahan masalah. Saat ini saya melanjutkan pengembangan kemampuan di bidang software engineering, algoritma, pemrograman, dan sistem digital. Saya terbiasa membangun proyek menggunakan PHP/Laravel, JavaScript, dan MySQL, serta terus mengeksplorasi C++, Linux Ubuntu, dan integrasi API.

Interested in software engineering, web applications, and intelligent systems.
