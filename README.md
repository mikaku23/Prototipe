# Portfolio Web Revamp

Struktur utama:

- `index.html` sebagai halaman utama
- `assets/js/dataProject.js` untuk seluruh data konten
- `assets/js/app.js` untuk render, theme toggle, language toggle, drawer, scroll spy, velocity scroll, dan counter animation
- `assets/css/style.css` untuk tampilan
- `assets/css/chatbot.css` dan `assets/js/chatbot-*` untuk chatbot floating tetap aktif

## Edit data
Tambahkan atau ubah isi konten di `assets/js/dataProject.js`.

## Catatan
- Mode terang/gelap disimpan di localStorage.
- Bahasa ID/EN juga disimpan di localStorage.
- Demo lama tetap ada di folder `proto1` sampai `proto5`.
