# TechNote App 2.0 Demo

Versi ini adalah demo static:
- `index.html` / `login.html` sebagai pintu awal
- `views/admin`, `views/dsn`, `views/mhs` untuk halaman role
- `assets/css/style.css` dan `assets/js/script.js` sebagai global
- Navigasi memakai href biasa
- Tidak ada CRUD, backend, atau session server
